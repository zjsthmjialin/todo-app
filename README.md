# JinSongToDo - 桌面待办事项应用

一款简洁美观的 Windows 桌面待办事项管理应用，采用原生界面风格设计。

## 功能特点

### 核心功能

* **任务管理**：添加、编辑、删除、完成任务

* **任务分类**：支持多个任务列表（我的日程、重要、计划等）

* **日期管理**：支持设置截止日期

* **任务筛选**：全部 / 进行中 / 已完成

* **搜索功能**：快速查找任务

* **进度追踪**：实时显示任务完成进度

### 特色功能

* **文件拖放**：直接将文件拖入窗口创建任务

* **数据导出**：支持导出为 Markdown、Excel、JSON 格式

* **数据导入**：支持从 JSON 文件导入任务

* **系统托盘**：最小化到系统托盘运行

* **窗口置顶**：可将窗口固定在最前端

* **主题颜色**：8 种预设主题颜色

## 系统要求

* Windows 10/11 (64位)

* 无需安装，直接运行

## 使用方法

### 运行应用

双击 `JinSongToDo.exe` 即可启动应用

### 快捷键

| 快捷键    | 功能       |
| ------ | -------- |
| Ctrl+N | 新建任务     |
| Ctrl+L | 显示/隐藏侧边栏 |
| Ctrl+Q | 退出应用     |

### 任务操作

* **添加任务**：在顶部输入框输入任务标题，按回车添加

* **完成任务**：点击任务左侧的复选框

* **编辑任务**：点击任务右侧的编辑按钮

* **删除任务**：点击任务右侧的 × 按钮

* **查看详情**：点击任务卡片展开/收起详情

### 数据存储

任务数据保存在应用目录下的 `tasks.db` SQLite 数据库文件中

## 界面预览

应用采用温暖的米黄色主题配色，搭配森林绿强调色，界面简洁舒适。

## 技术栈

* **框架**：PySide6 (Qt for Python)

* **数据库**：SQLite

* **打包**：PyInstaller
